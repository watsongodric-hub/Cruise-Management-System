# Cruise Management System

This is a Cruise Management System project developed using Python and MySQL.

## Description
The system helps manage cruise operations such as:
- Passenger details
- Cruise schedules
- Ticket booking
- Food services
- Luggage management

This project is created as part of a Computer Science academic project.

## Technologies Used
- Python
- MySQL
- MySQL Connector

## How to Run
1. Install Python (latest version)
2. Install MySQL
3. Install mysql-connector-python
4. Run the Python file
